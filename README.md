# X回复辅助

在 X 用户头像下显示互动与关注关系标签，帮你识别常来评论、互评回来的人，以及互关和未回关状态。

## 功能

- **爱回踩**：最近 3 天内，你评论对方后对方也评论了你，或对方评论了你至少 3 条不同的帖子。帖子数阈值可以调整，悬停标签可查看互动次数和命中规则。
- **已互关**：你和对方相互关注。
- **N 天未回关**：你已关注对方，对方尚未回关。
- **未关注**：你尚未关注对方。
- **关注了你**：对方关注了你，尚未确认互关。

各类标签可以在设置中单独开关。

## 安装

1. 点击仓库页面的 **Code → Download ZIP**，解压到固定文件夹。
2. 在 Chrome 中打开 `chrome://extensions`，开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
4. 打开并登录 X，刷新页面，点击扩展图标进入设置。

## 初始化

首次使用时，点击设置中的「一键初始化」。扩展会打开后台窗口，读取近期帖子、评论、通知和关注列表，建立互动记录。

每次读取最长 10 分钟。若中途关闭窗口或显示部分完成，可以点击「继续上次读取」。日常浏览 X 时，也会继续积累页面中出现的互动和关注关系。

统计范围取决于 X 实际加载的内容。多个账号请分别使用独立的 Chrome 浏览器配置。

### 为什么刚安装时显示「≥0天未回关」？

对于安装前就已关注的人，扩展从首次观察到这段关注关系时开始计时，因此刚开始会显示「≥0天」。这里表示已观察到的最短时长，不是你今天才关注了对方。之后会随时间增长。

如果扩展记录到了新的成功关注操作，就会从该次关注时间开始计时。

## 备份与更新

设置中可以导出和导入 JSON 备份，也可以查看最近 3 份自动备份。备份包含账号与互动记录，请妥善保管。

更新前先导出备份，再用新版文件覆盖原文件夹，在扩展管理页点击「重新加载」，最后刷新 X 页面。**不要卸载扩展**，以免丢失本地数据。

数据保存在本机浏览器中。卸载扩展或清理浏览器配置前，请先备份。
